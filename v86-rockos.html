RockOS on v86 (BIOS + IDE/ATA)

RockOS boots with SeaBIOS over BIOS, uses Multiboot1, and talks to disks through legacy IDE/ATA PIO ports (0x1F0/0x170). That matches v86's default PC emulation. UEFI is not used here.

Status

IMPORTANT: v86 cannot run this build yet. v86 emulates a 32-bit Pentium-class PC with no 64-bit/long-mode support, while RockOS is a 64-bit long-mode kernel (see src/arch/x86_64/boot.S). The page below is kept for QEMU/real-hardware reference and for after a 32-bit port exists. Pick files above, then Start. Defaults below use rockos.iso and rockos-data.img from this folder.

Recommended v86 settings are already in this page: SeaBIOS + cdrom: rockos.iso, hda: rockos-data.img, boot order 231 (CD first, then hard disk), 128MB RAM. Keep the hard-disk image persistent if you want RockFS to survive reboots.
